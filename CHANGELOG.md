# Changelog

## 0.3.0 — Advanced Motion Graphics Edition

- Added cinematic raster effects: vignette, film grain, bloom, chromatic aberration, scanlines, color grading, and digital glitch.
- Added chainable `ImageAsset` methods for the new raster effects.
- Added reusable Manim transition constructors: fade, directional slide, zoom, spin, and vector-create reveal.
- Added Manim motion helpers for shake and glow pulse.
- Added image-to-particle sampling, particle reveal/dissolve helpers, and kinetic typography helpers.
- Added advanced scene examples and expanded documentation with honest performance/feature limitations.
- Preserved the 0.2.0 legacy public API.

## 0.2.0

- Added chainable image operations, masks, compositing, GIF sequence loading, metadata handling, and expanded tests.
- Preserved the original Manim picture helper API.
